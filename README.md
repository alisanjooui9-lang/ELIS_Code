# 🌎 ELIS Code

### یک جهان آموزشی برای برنامه‌نویسی، ساختن و خلاقیت

ELIS Code پروژه‌ای از **ELIS Studio** است که با هدف ساخت یک دنیای آموزشی بزرگ برای برنامه‌نویسی و فناوری ایجاد شده است.

هدف ELIS Code این است که کاربر از سطح پایه شروع کند و در پایان بتواند با مهارت‌هایی که در مسیر یاد گرفته، پروژه‌ها و محصولات واقعی خودش را بسازد.

# 🗺️ نقشه آموزشی

هر حوزه دارای یک نقشه مرحله‌ای و بازی‌گونه است.

کاربر با تکمیل مراحل:

- مرحله‌های جدید را باز می‌کند
- XP دریافت می‌کند
- سکه دریافت می‌کند
- دستاورد می‌گیرد
- به فصل‌های بعدی می‌رود

هیچ دسته‌بندی جداگانه‌ای مثل Easy / Medium / Hard وجود ندارد.

سختی در خود مسیر آموزشی به‌صورت تدریجی افزایش پیدا می‌کند.

# 🧠 درس‌های واقعی

هدف ELIS Code این نیست که تعداد درس‌ها فقط با محتوای تکراری زیاد شود.

هر درس باید ارزش آموزشی واقعی داشته باشد.

یک درس می‌تواند شامل:

- آموزش مفهوم
- مثال
- کدنویسی
- تمرین
- سؤال
- آزمون
- چالش عملی
- نکات مهم
- خطاهای رایج
- کاربرد واقعی

باشد.

# 🎯 فلسفه ELIS Code

هدف فقط آموزش کدنویسی نیست.

هدف:

> یاد بگیر → تمرین کن → بساز → منتشر کن

کاربر نباید فقط در پایان یک دوره بگوید:

«من این زبان را یاد گرفتم.»

بلکه باید بتواند بگوید:

«با چیزی که یاد گرفتم، این پروژه را ساختم.»
